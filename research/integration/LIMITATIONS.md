# Limitations

This is reproducible experimental research, not production readiness, security
certification or evidence of a vulnerability in any upstream project.

Contract adequacy remains external. The catalog is independent of implementation
enumeration, but its authors are not organizationally independent from the engine's
authors. A pinned minimum contract prevents weakening this implemented claim type;
it does not synthesize a complete policy for arbitrary natural-language claims.
The final joint contract pins the separate native authority/model/scope policy as
well as both scenario profiles. Earlier unpublished development contracts without
that binding are archived as superseded inputs; their commitments are not reinterpreted
as including the new policy field.

The supported claim is a laboratory conjunction. Separate subject labels are not
equated. Proof/model authorization, original input admission, factual judgment truth,
external task success and global freshness require evidence absent here.

Key inequality is not controller inequality. Requesting the latter returns
UNVERIFIABLE. The replay/nonces interface is an offline snapshot, not a distributed
anti-replay service. Local tools and stable files are trusted during verification.

PR5's read accounting is observational. The joint boundary explicitly checks values
and refuses unknown fields, but this is not a general proof that arbitrary predicates
validate every value they read. The second crypto implementation runs on the same
machine; it is implementation diversity, not independent-party attestation.

The mutation report counts executed isolated controls, not all possible mutations.
Parser crashes never count as kills. The original PR6 fallback survivor remains in
its historical report; its new carrier-policy witness must not be described as
authorization with no preimage at all.

Runtime measurements include process startup and the actual unoptimized reference
implementation. Baselines share parts of the verification path; these numbers do
not estimate an optimized component verifier or support general performance claims.

ERC-8404's executable thin-slice and formal draft are separately versioned. Replaying
their preserved conformance package is not a certificate of universal ERC conformance.
The earlier literature comparison remains applicable; this integration asserts no
scientific novelty or new theorem.
