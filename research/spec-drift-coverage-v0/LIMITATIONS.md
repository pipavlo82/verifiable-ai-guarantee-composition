# Limits and independent review

Recommendation is bounded by executed controls, not by the number of green tests.
Claimed test coverage does not establish proven enforcement. A physical mutant
shows sensitivity at its specific changed site and witnesses, not that every
clause or path of an obligation is enforced. No one-mutant-per-obligation rule is
assumed. Broad source changes require human interpretation, not automatic repinning.

The live check observes only configured public repositories/branches/files at its
recorded time. It does not search every fork, validate ERC adoption, authenticate a
provider, compare Solidity implementation drift, or establish semantic compatibility.
TLS/API responses and selected upstream refs are trusted observation sources;
local digests do not constitute an independent cryptographic upstream attestation.

Backend execution evidence is historical and hash-verified. New local/fresh/CI runs
validate this reporter and existing regression gates; author replay is not independent
human or organizational review. An independently authored oracle is likewise not an
independent reviewer. Independent replay is NOT_COVERED for every checklist entry;
previous informal externally reported replay has no admitted attestation here and
is not retroactively invalidated. Same-profile second implementation is NOT_COVERED.

ERC-8004 remains limited to the existing finite Identity/Validation profiles, local
EVM, selected observations and EOA signatures. No universal compliance, production
security, validator truth, URI resolution, full event/storage coverage, ERC1271/7702
coverage, or external execution guarantee is added. ERC-8404 policy claims remain
separate from its receipt semantics. PR11 supplemental inputs are sibling evidence,
not merged code. Historical population counts must never be summed into a campaign.

Independent review should: verify exact base/head and all pins; inspect source clause
anchors and each guard/witness mapping; compare expected/observed/refusal axes; replay
offline controls in a fresh full clone; inspect raw source capture; deliberately
try false enforcement and independence metadata; check historical inventories;
then decide separately whether to integrate. No merge or ready-for-review action
is part of this experiment.
