# Laboratory artifact provenance

These are actual EIP-712 signatures generated by the preserved tools with fresh
ephemeral private keys. Keys were kept in process memory and were not written
to the repository, logs or Memory Palace. Replay verifies existing signatures;
it does not rerun generators or expect regenerated signatures to be identical.

The producer is this experiment. There is no external production observation,
on-chain transaction, chain admission, deployment authorization or execution
assertion. The domain chainId 31337 is declared laboratory context. LabJudgment
is an explicitly declared laboratory carrier, not a WYRIWE L4 attestation.

The RVR artifact is the preserved 380-byte native proof from v2. This consumer
checks its SHA-256 identity only; native validity is checked separately by the
historical replay. proofHash in these newly issued laboratory documents is
explicitly the SHA-256 of those bytes. No older document is reinterpreted.

The first author_independent/author_collision fixtures are retained developmental
artifacts. They did not include a contract-author identity allowlist entry.
The active additional-role scenarios use author_bound_independent and
author_bound_collision, which bind that role explicitly. All retained signatures,
including developmental ones, are checked by the second crypto implementation.

v4-self-witness and v4-self-policy are new controlled inputs to the unchanged v4
verifier. They are never substituted for historical v4 evidence. The generators
in tools/erc8404 identify every signing procedure and declared statement.
